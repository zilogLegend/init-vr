Descripción del Proyecto:

Este proyecto es una experiencia de Realidad Virtual diseñada para explorar el sistema de físicas de Unity aplicada a objetos interactivos. 
La aplicación permite al usuario experimentar con la gravedad, colisiones y materiales físicos a través de:
Laboratorio de Cubos: Una serie de cubos configurados con distintas propiedades físicas (masa, fricción, rebote).
Sistema de Baloncesto: Un balón funcional y una canasta modelada desde cero, donde se aplica el uso de Rigidbodies
Physic Materials y detección de colisiones para lograr un juego fluido y realista.
------------------------------------------------
Instrucciones para Ejecutar el Proyecto:
Para probar esta experiencia en tus Meta Quest 1, sigue estos pasos:
Requisitos previos:
Tener instalado Unity Hub y la versión de Unity correspondiente.
Haber habilitado el Modo Desarrollador en tu cuenta de Meta/Oculus.
Configuración del Proyecto:
Clona o descarga este repositorio.
Abre el proyecto en Unity.
Asegúrate de que la plataforma esté configurada en Android (File > Build Settings).
Instalación en Meta Quest:
Conecta el visor a la computadora mediante un cable USB-C.
En Unity, ve a Build Settings.
Haz clic en Build and Run.
Alternativamente, puedes generar el archivo .apk e instalarlo usando SideQuest.
